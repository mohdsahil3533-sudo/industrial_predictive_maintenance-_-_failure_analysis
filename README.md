## Project Overview

This project focuses on analyzing industrial machine failure patterns using the AI4I 2020 Predictive Maintenance Dataset.

The objective is to explore operational sensor parameters, identify patterns associated with machine failures, and develop actionable insights that can support preventive maintenance planning.

The analysis was performed using Microsoft Excel, including data validation, descriptive statistics, failure analysis, and an interactive-style analytical dashboard.

## Business Problem

Unexpected machine failures can disrupt industrial operations, increase maintenance costs, and affect production efficiency.

This project explores how operational parameters such as torque, tool wear, air temperature, and process temperature relate to observed machine failure rates.

## Key Findings

### 1. Torque Analysis
- Above 60 Nm recorded a 41.95% failure rate.
- The 20–40 Nm range recorded a 0.59% failure rate.

### 2. Tool Wear Analysis
- The 201–253 minute range recorded a 15.49% failure rate.
- The 151–200 minute range recorded a 2.90% failure rate.

### 3. Air Temperature Analysis
- The 303–305 K range recorded a 6.24% failure rate.
- The 297–299 K range recorded a 2.05% failure rate.

### 4. Process Temperature Analysis
- The 311–313 K range recorded a 3.88% failure rate.
- The 305–307 K range recorded a 2.33% failure rate.

## Business Recommendations

- Prioritize inspection of machines operating under high-torque conditions.
- Monitor machines with higher tool wear.
- Track temperature patterns during machine operation.
- Use observed failure patterns to support preventive maintenance inspection priorities.
- Continue monitoring operational parameters to identify potential maintenance risks.

## Limitations

- The AI4I 2020 dataset is synthetic and does not represent actual production-machine records.
- The analysis identifies statistical associations, not proven causal relationships.
- The analysis is exploratory and does not constitute a deployed real-time predictive maintenance model.
- The dataset does not contain time-series vibration readings for waveform-based analysis.

## Conclusion

This project demonstrates how Microsoft Excel can be used to analyze industrial sensor data, explore machine failure patterns, and communicate findings through an analytical dashboard.
